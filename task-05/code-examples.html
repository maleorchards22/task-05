Etiquetas de código y formato

Las etiquetas de código y formato son utilizadas para resaltar y dar estilo al texto en HTML. Algunas de las etiquetas más comunes incluyen:

Bloques de código

      
        // Este es un ejemplo de código en JavaScript
        function saludar(nombre) {
          return `Hola, ${nombre}!`;
        }

Saltos de línea

La etiqueta br se utiliza para insertar un salto de línea en el texto.

Ejemplo:

Esta es una línea de texto.
Esta es otra línea de texto.
