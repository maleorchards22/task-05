Ejemplos de etiquetas de texto

Las etiquetas de texto en HTML se utilizan para dar formato y estilo al contenido textual. A continuación, se presentan algunos ejemplos de etiquetas de texto comunes:

Etiquetas de párrafo

La etiqueta p se utiliza para definir un parrafo de texto. La etiqueta strong se utiliza para resaltar texto en negrita, mientras que la etiqueta em se utiliza para enfatizar texto en cursiva .

Etiquetas de cita

La etiqueta blockquote se utiliza para indicar una cita en bloque.

«Dos cosas son infinitas: el universo y la estupidez humana; y no estoy seguro del universo.» - Albert Einstein
